## 🚀 部署方式

### 方式一：GitHub Pages（免費推薦）

1. 在 GitHub 建立一個名為 `tongtaugarden` 的 repository
2. 將所有檔案上傳至該 repository
3. 進入 Settings → Pages → Source 選擇 `main` 分支
4. 等待約 1-2 分鐘，網站即上線於 `https://你的帳號.github.io/tongtaugarden/`

### 方式二：自訂網域 + 付費主機

1. 購買網域（建議 `tongtaugarden.com` 或 `tongtaugarden.hk`）
2. 選擇主機服務（如 Cloudflare Pages、Netlify、Vercel 均免費）
3. 將網域 DNS 指向主機服務
4. 上傳本目錄所有檔案即可

## 🔍 SEO 搜尋優化重點

### 讓 Google 搜尋到「唐頭園」的關鍵步驟：

1. **提交 Sitemap 到 Google Search Console**
   - 前往 [Google Search Console](https://search.google.com/search-console)
   - 新增網站並驗證擁有權
   - 提交 `sitemap.xml` 讓 Google 快速索引

2. **每頁都有完整的 Meta 標籤**
   - 所有頁面已內建 `description`、`keywords`、`og:` 標籤
   - 品牌名稱「唐頭園」出現在 title、description、keywords 中

3. **內容持續更新**
   - 定期更新 blog.html 的內容
   - 每篇文章都包含「唐頭園」關鍵字

4. **取得外部連結**
   - 在 Instagram、Facebook、YouTube 等社群平台連結回官網
   - 在相關論壇或社群提及「唐頭園」並附上連結

5. **申請 Google 商家檔案**（如在香港有實體據點）
   - 增加在地搜尋曝光
